# Dhruvil Tic

A small tic-tac-toe game for your phone.

- **vs Computer**: a smart AI that slips up now and then, so you can still win
- **2 Players**: pass the phone back and forth
- Keeps score, switches who goes first each game, and vibrates when you tap
- Works offline and can be installed to your home screen (it's a PWA)

## Play

Open `index.html` in a browser. To put it on a phone, host the folder anywhere
(for example, GitHub Pages: Settings → Pages → deploy from this branch). Then open the link
on the phone and choose **Add to Home Screen**. It opens full screen like a normal app.

To try it on your computer: `python3 -m http.server` then open http://localhost:8000
